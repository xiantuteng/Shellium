## 二、核心主线手工验收

以下用例必须在隔离的受控服务器执行，不能仅依赖单元测试。

### 当前层自动识别

- [ ] 连接第 1 层后，状态栏和文件管理器显示同一服务器；
- [ ] 在第 1 层执行 `ssh user@layer2`，第 2 层认证成功前不得提前加入服务器链；
- [ ] 第 2 层成功后，文件管理器自动切换到第 2 层；
- [ ] 列目录、上传并下载一个带唯一内容的文件，确认操作发生在第 2 层；
- [ ] 关闭“跟随最内层”，切换到第 1 层并验证独立路径；
- [ ] 第 2 层执行 exit 后自动返回第 1 层；
- [ ] 使用 `command ssh` 绕过 Shell Integration，界面必须显示“推测”而非“已确认”；
- [ ] Shell Integration 安装失败时，普通 SSH 连接仍可用且有降级提示；
- [ ] 服务器禁用 AllowTcpForwarding 时，exec 中继可建立内层会话。

### SFTP

- [ ] 本地/远程双栏浏览与路径直达；
- [ ] 文件和目录双向拖拽；
- [ ] 递归上传/下载、暂停、恢复、取消和失败清单；
- [ ] 中断后断点续传，完整文件哈希一致；
- [ ] 文本/图片预览不执行远程内容，超限文件被拒绝；
- [ ] chmod、重命名、文件删除、空目录删除；
- [ ] 终端右键上传固定进入同标签当前层目录；
- [ ] 两个标签连接不同服务器时，路径、队列和凭据不串用。

## 三、连接、安全与恢复

- [ ] 设置中可启用/关闭主密码保护；启用需设置并确认新密码，关闭需重新验证当前密码；
- [ ] 双向切换会原子迁移全部凭据；关闭成功后清除保险箱配置，主密码不出现在数据库和日志；
- [ ] 忘记主密码时可输入“重置保险箱”执行二次确认；重置原子清除凭据、主机引用和旧密钥，
      保留地址、账号、端口、私钥路径、分组及主机链，取消启动解锁仍可进入应用；
- [ ] 主机密码和私钥路径自动保存；未启用主密码保护时点击眼睛图标会提示开启且不显示明文；
- [ ] 复制主机会克隆独立凭据；历史共享 credential_id 升级后自动拆分；
- [ ] 错误主密码、损坏校验块、孤立凭据均不会覆盖原数据；
- [ ] 保存主机凭据后重启，解锁并连接成功；
- [ ] 15 分钟闲置自动锁定；用户活动正确续期；
- [ ] OpenSSH config 导入，Shellium JSON 往返，导出文件不含凭据关键字；
- [ ] 新主机指纹人工确认，已知主机变更被阻止；
- [ ] 旧 hmac-sha1 只对用户确认的单个目标生效；
- [ ] 正常 exit 不自动重连；
- [ ] 已建立会话异常断线按配置退避重连，次数耗尽后回到本地 Shell；
- [ ] 连接历史完整记录成功、失败、重试和断开时间。

- [ ] -R 服务端监听可回连本机目标；

- [ ] autoStart 仅在绑定主机成功连接后启动；
- [ ] 活动连接数、累计连接数和双向字节统计正确；
- [ ] 停止规则、断开 SSH、关闭标签时所有监听器、线程和 fd 被释放；
- [ ] 同一保存主机打开两个标签时，远程入站连接不会投递到错误运行时。
