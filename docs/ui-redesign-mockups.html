要点
  • 选中态：accent 16% 透明度做底色、45% 透明度做描边，直接叠在当前实际背景上——不管系统外观和应用内主题是否一致，同一份颜色永远读得清，不会像早期版本那样因为深浅判断错误而画出一块看不清文字的深色块。

Dialog · HostChainDialog / HostPickerDialog

编辑主机链

受管主机链和自由文本 ProxyJump 是两套互斥的路由表达（同时启用会跳两次），因此编辑器里刻意不做"文本框 + 逗号分隔"，改成可拖拽排序的跳板列表 + 固定不可编辑的目标主机卡片，让"经过谁、最后到哪"在结构上就分得清楚，不需要解析一行文本。

要点
  • 拖拽手柄（六个圆点）只出现在链路中的跳板行上——目标主机卡片用虚线描边和"目标主机"小标签明确标出"这一项不能拖、不能删、不属于列表"，避免用户对着它找不到抓取点而困惑。
  • "添加主机"打开的是一个独立的轻量选择器（"选择跳板机"），复用主机管理里已经保存的主机，而不是重新填一遍地址/账号/端口；同一个选择器里也留了"新建主机"入口，两条路径最终都汇入同一个列表。
  • "从链路移除"只对列表里当前选中的跳板行生效，永远不会碰目标主机——按钮默认置灰，选中一行后才可用，避免"删除"这个危险动作在没有明确选中目标时被误触发。
  • 主机配置对话框里的 ProxyJump 文本框在主机链非空时置灰，两者互斥而不是同时生效——避免用户以为两边都在起作用，实际却被系统悄悄按主机链优先级忽略掉其中一个。

同一个对话框按 CredentialVault::State 分两种形态，字段和文案都已经和实现一致；这版补的是视觉：顶部加一个安静的锁形徽标锚定"这是安全相关操作"，卡片标题从大段说明文字收成"小标题 + 居中说明"，创建模式下"无法找回"的提醒从纯段落文字改成带图标的醒目提示框，错误态改成红色描边 + 字段下方短句，不再是孤立的红色文字。

要点
  • 顶部锁形徽标只在这一类"需要主密码"的对话框出现，是它和新建主机/新建分组等普通表单在第一眼就能区分开的信号，不需要每次读标题文字才知道这是安全操作。
  • 错误态改成红色描边 + 字段正下方的短句：原来的实现是把红色提示放在整张卡片下方，字段本身没有任何视觉标记，用户得先读完文字才知道是哪个字段错了。
  • "主密码无法找回"从一段夹在说明文字里的话，独立成带警示图标的提示框——这是唯一一次性提醒、后悔药买不到的信息，值得单独占一块视觉空间。
  • 取消按钮左对齐、主操作右对齐，和主机/分组对话框的 footer 节奏保持一致；不允许取消的场景（保险库首次创建且被强制要求）时直接不渲染取消按钮，而不是禁用它。
